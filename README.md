# PDF Ninja

Edit Word documents and convert Word to PDF and back, on iPhone and iPad. Everything runs on the device; files are never uploaded.

Live app: https://makergreg9000.github.io/PDF/

## Install on iPhone or iPad
1. Open the link above in Safari.
2. Tap Share (the square with an arrow).
3. Tap **Add to Home Screen**, then **Add**.

## Files
- `index.html` the whole app
- `manifest.webmanifest` app name, icon and full-screen mode
- `icons/` the app icon
- `.github/workflows/pages.yml` publishes `main` to GitHub Pages on every push
